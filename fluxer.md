# Fluxer
Fluxer is FishingBucket's primary platform and the platform with the largest community.

## Community

## Features
### Proxying
Proxying on Fluxer uses Fluxer webhooks, which carries only username and profile picture information. Limitations of this method include the inability to customize the webhook's name color, as well as the inability to view the proxy of a message in detail.

### Reply
Fluxer webhooks have the ability to natively reply to messages, providing a platform-sanctioned way to do structured conversation without workarounds. However, due to the fact that proxying uses webhooks, reply pings must be emulated with a prefix to the message. Furthermore, reply ping preferences is also unable to be carried over.

### External Emojis
External emojis can be used without having the bot be in the community with said emojis.
